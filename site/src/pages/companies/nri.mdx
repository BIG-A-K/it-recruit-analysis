株式会社野村総合研究所（NRI）は、リサーチと経営コンサルティング、システムコンサルティングからシステム開発・運用までを一貫して提供するシンクタンク・ITサービス企業。[第61期有価証券報告書](https://api.edinet-fsa.go.jp/api/v2/documents/S100YBM8)による2026年3月期末の連結従業員数は16,894名、単体従業員数は7,982名、単体資本金は25,655百万円。

> NRIグループは、「使命」「創発する社会」「私たちの価値観」を柱とした普遍的な企業理念を掲げています。 ([企業理念](https://www.nri.com/jp/company/c_philosophy.html))

## 採用情報
### 新卒

採用主体は株式会社野村総合研究所。2028年度新卒採用は[新卒採用サイト](https://working.nri.co.jp/recruit/2028/)でインターンシップやイベントを案内している（2027年度新卒の正式応募受付は終了）。キャリア採用は[キャリア採用サイト](https://career.nri.co.jp/)で随時募集している。

職種と待遇の内訳は[2027年度新卒採用の募集要項](https://working.nri.co.jp/recruit/2027/contents/recruiting/application.html)に基づく。総合職とエリア総合職の2コース制で、いずれも応募資格は「2027年3月末までに国内外の四年制大学卒業見込、または大学院修了見込（全学部・全学科、国籍不問。卒業後3年以内も応募可能）」。

総合職の募集職種は次の5つ。

| 職種 | 仕事内容 |
| --- | --- |
| 経営コンサルタント | あらゆる業界の顧客の課題に対峙するコンサルティング（企業の戦略策定、業務改革、官公庁の政策提言など） |
| アプリケーションエンジニア | 金融・流通・産業など顧客業務の課題解決や新たな付加価値・ビジネス創造を目的としたシステムの企画・設計・開発 |
| テクニカルエンジニア | クラウド・オンプレミスを活用したIT基盤の設計・構築・運用、開発生産性を向上させるフレームワークや手法の開発 |
| セキュリティスペシャリスト | セキュリティコンサルティング、診断、監視、ソリューション開発などセキュリティの専門業務 |
| 経理スペシャリスト | 本社部門・各事業部門における企業会計全般（法務スペシャリストの募集はなし） |

エリア総合職は「エリア職システムエンジニア（札幌・福岡）」。札幌（NRI札幌開発センター）は大規模システムの設計・開発と、クラウドネイティブ・データアナリティクスを活用したシステム構築を担う。福岡（NRI福岡開発センター）は金融向けDXシステム、産業・流通向けクラウドネイティブシステム、AI/IoTソリューション開発、先端技術のR&Dを担う。

## 事業内容

[第61期有価証券報告書](https://api.edinet-fsa.go.jp/api/v2/documents/S100YBM8)の報告セグメントは、主たるサービスの性質と顧客・マーケットを総合的に勘案して次の4区分としている。各セグメントの金額は2026年3月期。

| 報告セグメント | 事業内容・提供サービス | 主な関係会社 |
| --- | --- | --- |
| コンサルティング | 政策提言、戦略コンサルティング、業務改革を支援する業務コンサルティング、ITマネジメント全般のシステムコンサルティング | — |
| 金融ITソリューション | 証券業・保険業・銀行業など金融業向けのシステムコンサルティング、システム開発・運用、共同利用型システム、BPOサービス | NRIプロセスイノベーション、だいこう証券ビジネス、DSB情報システム、日本証券テクノロジー、Australian Investment Exchange |
| 産業ITソリューション | 流通業・製造業・サービス業・公共向けのシステムコンサルティング、システム開発・運用のITソリューション | NRIネットコム、NRIシステムテクノ、NRI Australia、Convergence Technologies |
| IT基盤サービス | データセンター運営管理、IT基盤・ネットワーク構築、情報セキュリティサービス、新事業・新商品の開発、先端情報技術の調査・研究 | NRIセキュアテクノロジーズ、NRIデータｉテック |

グループ全体のサービスは、コンサルティングサービス、開発・製品販売、運用サービス、商品販売の4種類に整理されている。主要な外部顧客は親会社の野村ホールディングス（金融ITソリューション、2026年3月期 86,693百万円）。

:::warn
2026年3月期は産業ITソリューションが97,060百万円の減損損失を計上し、同事業の営業利益が△74,616百万円となった。これにより連結営業利益は前期の134,907百万円から58,273百万円へ半減している。前年との単純比較には注意。
:::
