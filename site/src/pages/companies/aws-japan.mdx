AWSは2006年にサービスを開始したクラウドプラットフォームです。公式サイトでは、スタートアップ、企業、非営利団体、政府・自治体などへコンピューティング、ストレージ、データベース、AIなどの基盤を提供すると説明しています。

採用サイトでは「地球上で最もお客様を大切にする企業であること」を理念の一つに挙げ、顧客の課題から逆算する考え方を重視しています。

## 採用情報

### 新卒

採用主体はアマゾン ウェブ サービス ジャパン合同会社です。2026年8月2日に公式新卒採用ページを確認しました。

| 職種 | 確認できた募集状況 |
| --- | --- |
| [営業](https://aws.amazon.com/jp/careers/newgraduate/commercialsales/) | 新卒採用ページで応募予定職種として案内 |
| [サポートエンジニアリング](https://aws.amazon.com/jp/careers/newgraduate/supportengineering/) | クラウドサポートエンジニアの職種情報を掲載 |
| [ソリューションアーキテクト](https://aws.amazon.com/jp/careers/newgraduate/solutionsarchitect/) | 2027年卒本選考を案内 |
| [プロフェッショナルサービス](https://aws.amazon.com/jp/careers/newgraduate/Proserve/) | 2028年卒インターンを案内 |
| [データセンター](https://aws.amazon.com/jp/careers/newgraduate/datacenter/) | 2027年卒向けの施設・ITインフラ職を案内 |

新卒採用ページでは初任給、固定残業、標準年収を確認できなかったため、金額は掲載していません。応募時には各職種のAmazon Jobs募集要項で最新条件を確認する必要があります。

データセンター部門では、電気・機械設備を運用するDCEOと、サーバー・ネットワーク機器を運用するDCOを紹介しています。DCOの主な領域はキャパシティ・インストール、障害対応、機器の廃止です。

### 選考・働き方

[採用プロセス](https://aws.amazon.com/jp/careers/recruiting/)では、多くのポジションについて書類選考、一次面接、最終面接、内定という流れを案内しています。応募から内定までは1〜1.5か月程度が目安で、面接ではAmazonのLeadership Principlesに基づく行動事例が確認されます。

公式採用ページは東京、大阪、名古屋、福岡の募集検索を案内しています。採用担当者の説明では会社都合の転勤はなく、基本は週3日のオフィス出社としつつ、職種やマネージャーとの相談により柔軟な働き方が可能とされています。

[福利厚生ページ](https://aws.amazon.com/jp/careers/benefit/)では、年1回の査定、通勤手当、確定拠出年金、社会保険、初年度最大14日の有給休暇、年間最大5日のパーソナル休暇、対象社員へのAmazonのRSU付与を案内しています。
