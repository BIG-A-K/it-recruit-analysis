厚生労働省（MHLW）は、健康・医療、福祉・介護、雇用・労働、年金を所管する中央省庁。英称は Ministry of Health, Labour and Welfare。所在地は〒100-8916 東京都千代田区霞が関1-2-2 中央合同庁舎第5号館。法人番号は6000012070001。

社会保障制度の多くが社会保険という共助の仕組みで運営されるため、[年金・医療・介護の将来推計や統計分析](https://www.mhlw.go.jp/stf/kouseiroudoushou/saiyou/suuri.html)に数理科学の専門知識を用いる。あわせて全国の行政サービスを支える多数の情報システムを保有し、その企画・開発・調達とセキュリティ確保を省内で担う。

## 組織

[内部部局](https://www.mhlw.go.jp/kouseiroudoushou/shigoto/)は次の13部局。感染症対策部は健康・生活衛生局、安全衛生部は労働基準局、障害保健福祉部は社会・援護局に置かれる。

| 内部部局 | 主要業務 |
| --- | --- |
| 大臣官房 | 人事、会計、総合調整、国際、厚生科学 |
| 医政局 | 医療提供体制、医療従事者、医療DX |
| 健康・生活衛生局 | 健康増進、感染症対策、食品衛生、水道 |
| 医薬局 | 医薬品・医療機器の承認審査、薬事監視 |
| 労働基準局 | 労働条件、労災補償、安全衛生 |
| 職業安定局 | 雇用対策、雇用保険、ハローワーク |
| 雇用環境・均等局 | 雇用均等、両立支援、労働紛争解決 |
| 社会・援護局 | 生活保護、地域福祉、障害保健福祉 |
| 老健局 | 介護保険、高齢者福祉 |
| 保険局 | 医療保険、診療報酬 |
| 年金局 | 公的年金制度、年金財政、数理 |
| 人材開発統括官 | 職業能力開発、技能検定 |
| 政策統括官 | 政策の総合調整、統計、情報政策 |

情報システムと統計を所管するのは[政策統括官](https://www.mhlw.go.jp/content/001123535.pdf)の組織。[一般職デジタル・電気・電子区分の採用窓口](https://www.mhlw.go.jp/general/saiyo/kokka2/kokka2-kousei/den-jouhou.html)は政策統括官付参事官付統計・情報総務室、[総合職数理・デジタル系の採用窓口](https://www.mhlw.go.jp/stf/kouseiroudoushou/saiyou/suuri.html)は年金局数理課が務める。

地方支分部局は[地方厚生（支）局](https://www.mhlw.go.jp/stf/kouseiroudoushou/chihoukouseikyoku/index.html)と[都道府県労働局](https://www.mhlw.go.jp/stf/kouseiroudoushou/roudoukyoku/index.html)。都道府県労働局の下に労働基準監督署と公共職業安定所（ハローワーク）が置かれる。ほかに[施設等機関](https://www.mhlw.go.jp/stf/kouseiroudoushou/sisetu/index.html)と[中央労働委員会](https://www.mhlw.go.jp/churoi/)がある。

## 主要業務（情報系学生関連）

- **医療DX**: [医療DXの推進に関する工程表](https://www.mhlw.go.jp/stf/iryoudx.html)に基づき、全国医療情報プラットフォームの創設、電子カルテ情報の標準化等、診療報酬改定DXの3本柱を進める
- **標準型電子カルテ・介護情報基盤**: 医療機関向けの標準型電子カルテ（導入版）と、介護情報基盤の構築
- **オンライン資格確認**: 医療費助成のオンライン資格確認について、医療機関・薬局、レセコンベンダ、自治体システムベンダ向けの仕様を整備
- **データヘルス改革**: [データヘルス改革推進本部](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/0000148743.html)を省内に設置し、健康・医療・介護分野を連結するICTインフラを部局横断で検討
- **マイナンバー制度**: [厚生労働分野のマイナンバー制度](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/0000062603.html)の施行、医療保険・雇用保険・生活保護等の情報連携
- **業務システムの企画・調達**: 雇用保険や労働保険をはじめとする業務システムの開発・刷新、調達の審査・評価・指導、情報セキュリティ対策
- **統計・数理**: [各種統計調査](https://www.mhlw.go.jp/toukei_hakusho/toukei/)の作成と、年金・医療保険・介護保険の現状分析および将来推計

## 採用情報

採用主体は厚生労働省。情報系学生に対応する新卒の入口は、総合職の「数理・デジタル系」と一般職の「デジタル・電気・電子区分」の2つ。

| 区分 | 応募ルート | 主な業務 |
| --- | --- | --- |
| [総合職（数理・デジタル系）](https://www.mhlw.go.jp/stf/kouseiroudoushou/saiyou/suuri.html) | 国家公務員採用総合職試験（院卒者試験・大卒程度試験）の「数理科学・物理・地球科学」「デジタル」区分 | 年金・医療・介護・雇用・労災など社会保障分野の企画立案、統計の作成、現状分析と将来推計、業務システムの開発・刷新に係る調達 |
| [一般職（デジタル・電気・電子区分）](https://www.mhlw.go.jp/general/saiyo/kokka2/kokka2-kousei/den-jouhou.html) | 国家公務員採用一般職試験（大卒程度試験） | 省が保有する情報システムの企画・立案・運用、調達に係る審査・評価・指導、情報セキュリティ対策、省内のICT化の強化 |
| [数理・デジタル系 選考採用](https://www.mhlw.go.jp/stf/kouseiroudoushou/saiyou/index_00002.html) | 選考（課長補佐級・係長級） | 数理的な素養を活かした社会保障・労働分野の企画立案、統計と将来推計、業務システムの開発・刷新に係る調達 |
| [経験者採用・選考採用](https://www.mhlw.go.jp/stf/newpage_21892.html) | 選考 | 各部局の行政事務 |
| [任期付職員](https://www.mhlw.go.jp/stf/kouseiroudoushou/saiyou/ninkituki/index.html) | 選考 | 募集ごとに指定された分野の専門業務 |

数理・デジタル系の[専攻分野に指定はなく](https://www.mhlw.go.jp/stf/kouseiroudoushou/saiyou/suuri.html)、数学・デジタル以外を専攻した採用者も多い。関係団体では[社会保険診療報酬支払基金](https://www.ssk.or.jp/aboutkikin/saiyou/shokuin/index.html)と[国民健康保険中央会](https://www.kokuho.or.jp/recruit/)が医療DX関連人材を採用する。
