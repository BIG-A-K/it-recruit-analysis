## 採用情報

### 新卒

採用主体は株式会社マクニカ（事業会社）。[新卒募集要項](https://www.macnica.co.jp/recruit/entry/requirements/)は2027年4月入社（27卒）のエントリーを終了し、2028年4月入社（28卒）を受け付けている。初任給は2025年4月実績。勤務地は全職種共通で本社（横浜）を中心に配属により国内外の拠点へ転勤あり。

| 職種群 | 初任給（月）※1 |
| --- | --- |
| [ビジネスドライブ職](https://www.macnica.co.jp/recruit/entry/requirements/) | 一般職種群: 大学院卒 312,390円／大学卒・高専卒 300,110円 |
| [エンジニア職](https://www.macnica.co.jp/recruit/entry/requirements/) | 一般職種群に同じ |
| [コーポレート職](https://www.macnica.co.jp/recruit/entry/requirements/) | 一般職種群に同じ |
| ビジネスオペレーション職 | 250,380円 |

<p class="section-note"><small>※1 初任給は2025年4月実績。ビジネスドライブ職・エンジニア職・コーポレート職は一般職種群の給与水準で、大学院卒の内訳は基礎給267,000円＋固定時間外手当45,390円。賞与は年2回（6月・12月）、支給額は非開示。所定労働時間は8:45〜17:15（実働7.5時間）、年間休日125日、入社1年目は原則出社。</small></p>

## 事業内容

公式[事業紹介](https://www.macnica.co.jp/business/)は次の14区分。

- 半導体／ネットワーク／セキュリティ／CPSセキュリティ／コネクティビティ
- スマートマニュファクチャリング／スマートシティ・モビリティ／サービスロボット
- AI／DX／コンサルティング
- サーキュラーエコノミー／ヘルスケア／フード・アグリテック

[第11期有価証券報告書](https://disclosure2dl.edinet-fsa.go.jp/searchdocument/pdf/S100YGVR.pdf)の報告セグメントは、半導体・電子デバイスのディストリビューションとITソリューション・サービスの2区分。

| 報告セグメント | 主な事業・製品・サービス |
| --- | --- |
| IC・電子デバイスその他事業 | 半導体・電子デバイスのディストリビューション、技術サポート、リファレンスデザイン。プロセッサ（CPU・GPU・FPGA）、メモリ、センサ、電源デバイス、無線通信用IC等。 |
| サイバーセキュリティ・その他ITソリューション事業 | ネットワーク・セキュリティ機器の販売・構築、AI・DXソリューション、スマートマニュファクチャリング、スマートシティ・モビリティ、サービスロボット、サーキュラーエコノミー、ヘルスケア等のソリューションサービス。 |

:::warn
FY2026有価証券報告書で報告セグメントを組替え、従来の「ネットワーク事業」を「サイバーセキュリティ・その他ITソリューション事業」へ再分類した。FY2025の比較数値は遡及組替を行っているが、FY2024以前は旧区分（ネットワーク事業）のままであり、区分変更前後の単純な時系列比較はできない。
