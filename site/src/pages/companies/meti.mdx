経済産業省（METI）は[経済産業省設置法](https://www.meti.go.jp/intro/data/a220001j.html)（平成11年法律第99号）に基づく中央省庁。2001年（平成13年）1月6日の中央省庁再編で通商産業省（MITI）から改組された。任務は民間の経済活力の向上、対外経済関係の円滑な発展を中心とした経済・産業の発展、鉱物資源・エネルギーの安定的かつ効率的な供給の確保。

所在地は〒100-8901 東京都千代田区霞が関1-3-1。法人番号は4000012090001。

## 組織

[各部署の業務](https://www.meti.go.jp/intro/data/a220001j.html)による内部部局は次のとおり。商務情報政策局がIT・デジタル政策を統括し、情報系学生の主要な配先。

| 内部部局 | 主要業務 |
| --- | --- |
| 大臣官房 | 人事、会計、法令案審査、公文書管理、政策評価、広報、省内DX推進。産業保安・安全グループを併設 |
| 経済産業政策局 | 経済・産業構造政策、産業人材、経済分析、統計、地域経済産業政策 |
| 通商政策局 | 通商戦略、EPA/FTA、経済連携、国際ルール形成 |
| 貿易経済安全保障局 | 貿易管理、安全保障貿易管理（外為法・輸出管理等）、経済安全保障推進。2024年7月改編で貿易経済協力局から改称 |
| イノベーション・環境局 | 技術革新、産学連携、環境政策、量子産業政策。2024年7月改編で新設 |
| 製造産業局 | 鉄鋼・自動車・航空機・宇宙・ロボット・素材・バイオ等の製造業政策 |
| 商務情報政策局 | 情報通信産業、データ政策、AI、半導体、サイバーセキュリティ、商取引、流通、サービス産業政策 |

商務情報政策局の主要課室は[情報経済課](https://www.meti.go.jp/policy/mono_info_service/joho/index.html)、[サイバーセキュリティ課](https://www.meti.go.jp/policy/netsecurity/index.html)、情報産業課（[デバイス・半導体戦略室](https://journal.meti.go.jp/kaitaishinsho/29867/)）、コンテンツ産業課。

[外局](https://www.meti.go.jp/intro/data/a220001j.html)は資源エネルギー庁、特許庁、中小企業庁の3庁。地方支分部局は北海道・東北・関東・中部・近畿・中国・四国・九州の経済産業局（各局に産業保安監督部）。

## 主要業務（情報系学生関連）

- **AI・データ政策**: [GENIAC（Generative AI Japan Challenge）](https://www.meti.go.jp/policy/mono_info_service/geniac/index.html) による国産大規模言語モデル開発支援。AI事業者ガイドラインの三省庁体制（デジタル庁・総務省・経済産業省）で所管
- **半導体・デバイス**: [半導体・デジタル産業戦略検討会議](https://www.meti.go.jp/policy/mono_info_service/joho/conference/semicon_digital.html) 事務局。次世代半導体量産、次世代通信（ポスト5G）、AIロボット・フィジカルAIを見据えたマルチモーダル基盤モデル開発
- **サイバーセキュリティ**: 産業サイバーセキュリティ、サプライチェーン対策。内閣官房NISCと連携
- **標準化・規格**: [日本産業規格（JIS）](https://www.meti.go.jp/policy/economy/hyojun-kijun/index.html) の制定・改正、国際標準化戦略
- **経済安全保障**: 技術流出対策、指定安定供給製品制度、重要技術基盤指導制度
- **スタートアップ**: [スピンオフ活用](https://www.meti.go.jp/policy/newbusiness/index.html)、ディープテック・スタートアップ支援

## 採用情報

採用主体は経済産業省。[新卒採用情報](https://www.meti.go.jp/information/recruit/index.html)に掲載される主な採用区分は次のとおり。

| 区分 | 特徴 |
| --- | --- |
| 総合職（事務系・技術系） | [国家公務員採用総合職試験](https://www.jinji.go.jp/saiyo.html)を経て[官庁訪問](https://www.meti.go.jp/information/recruit/kanchohomon/kanchohomon_sogo_index.html)後に採用 |
| 一般職 大卒程度 事務系／技術系 | 一般職試験を経て採用 |
| 一般職 高卒程度 事務系・技術系 | 一般職試験（高卒程度）を経て採用 |
| [経験者採用（キャリア）](https://www.meti.go.jp/information/recruit/career/index.html) | 民間企業等での実務経験を活かす中途採用 |

採用PI「[PEOPLE](https://www.meti.go.jp/information/recruit/index.html)」は、商務情報政策局（情報経済課・サイバーセキュリティ課）、資源エネルギー庁、貿易経済協力局、中小企業庁、JETRO出向など多様なキャリアパスを提示する。キャッチコピーは「流れを、変える。流れを、創る。」。

:::info
給与表と採用プロセスの全体像（総合職試験・官庁訪問の流れ、デジタル区分の申込倍率、級・号俸のモデル年収）は[中央省庁 業界ページ](/industries/public-sector/)に整理した。省庁別の給与は公表されておらず、本ページでは省略する。
:::

### 令和7年4月1日現在の総合職採用実績

[区分試験別・府省等別採用状況（令和7年4月1日現在）](https://www.jinji.go.jp/content/000012088.pdf)における経済産業省の総合職採用実績は計54人（うち女性19人）。うち院卒者試験デジタル区分6人、大卒程度試験デジタル区分1人。

採用実績は年度ごとに増減する。2027年度の採用予定は[府省等別採用予定数及び官庁訪問窓口一覧](https://www.jinji.go.jp/content/000015294.pdf)で確認する。
:::

### 令和8年度予算

[令和8年度当初予算の概要](https://www.meti.go.jp/main/yosan/yosan_fy2026/pdf/01.pdf)による経済産業省関係合計は**3兆0,693億円**（令和7年度当初 2兆0,524億円）。主な内訳は次のとおり。

| 会計・区分 | 令和8年度当初 | 令和7年度当初 |
| --- | ---: | ---: |
| 一般会計（エネ特繰入除く） | 3,754億円 | 3,525億円 |
| エネルギー対策特別会計 計 | 2兆5,333億円 | 1兆5,455億円 |
| 　AI・半導体関連 | **1兆2,390億円** | 3,328億円 |
| 　GX推進対策費（AI・半導体除く） | 6,050億円 | 5,042億円 |
| 特許特別会計 | 1,606億円 | 1,544億円 |

AI・半導体関連予算は前年度比約3.7倍。主な事業は「AIロボット・フィジカルAIを見据えたマルチモーダル基盤モデル開発事業」（3,873億円、新規）、「ポスト5G情報通信システム基盤強化研究開発事業」（6,738億円）、次世代半導体の量産等に向けた出資事業（1,500億円）、半導体設計・製造基盤整備（令和7年度補正 988億円）。
