警察庁（NPA）は[警察法](https://www.npa.go.jp/about/overview/sikumi.html)に基づき、国家公安委員会の管理の下に置かれる行政機関。長は警察庁長官。警察法は昭和22年に制定され、昭和29年の全面改正で警察運営の単位が現在の都道府県警察に一元化された。

警察庁は広域組織犯罪への対処態勢、犯罪鑑識、犯罪統計等について[都道府県警察を指揮監督](https://www.npa.go.jp/about/overview/sikumi.html)する。都道府県には都道府県公安委員会が置かれ、都道府県警察（東京都は警視庁）を管理する。所在地は〒100-8974 東京都千代田区霞が関2-1-2。

## 組織

警察庁は[長官官房と5つの局、3つの部](https://www.npa.go.jp/about/overview/sikumi.html)からなる内部部局、3つの附属機関、地方機関として6つの管区警察局等を置く。

| 内部部局 | 主要業務 |
| --- | --- |
| 長官官房 | 機密、所管行政の企画・立案・総合調整、法令案審査、広報、情報公開、個人情報保護、警察職員の人事・定員、監察、予算決算会計、警察通信、警察装備、国際協力 |
| 生活安全局 | 市民生活の安全と平穏、地域警察・警ら、犯罪予防、保安警察 |
| 刑事局 | 刑事警察、犯罪鑑識、犯罪統計 |
| 組織犯罪対策部 | 国際犯罪捜査、ICPO連絡、暴力団対策、薬物・銃器犯罪取締り、犯罪収益移転防止 |
| 交通局 | 交通警察 |
| 警備局 | 警備警察 |
| 外事情報部 | 外国人またはその活動の本拠が外国にある日本人に係る警備警察 |
| 警備運用部 | 警衛、警護、警備実施、警察法第71条の緊急事態対応 |
| [サイバー警察局](https://www.npa.go.jp/bureau/cyber/what-we-do/about.html) | サイバー事案に関する警察、犯罪の取締りのための情報技術の解析 |

[サイバー警察局](https://www.npa.go.jp/bureau/cyber/what-we-do/about.html)は令和4年（2022年）4月1日に新設。官民連携、人材育成、各国との情報交換、サイバー事案の捜査指導、高度な解析への技術支援を推進する。令和8年4月には「警察におけるサイバー戦略」を改定し、今後5年間の取組を定めた。

[サイバー特別捜査部](https://www.npa.go.jp/bureau/cyber/what-we-do/about_ncu.html)は、重大サイバー事案へ対処する国の捜査機関。関東管区警察局に設置され、外国捜査機関等と連携して高度技術を要する事案や海外からのサイバー攻撃に対処する。

[サイバーフォース](https://www.npa.go.jp/bureau/cyber/what-we-do/cyberforce.html)は、サイバー事案の未然防止および技術的な緊急対処を担う部隊。警察庁および都道府県等の情報通信部に設置され、警察庁のサイバーフォースセンターが全国の司令塔となる。リアルタイム検知ネットワークシステムを24時間体制で運用する。

附属機関は[警察大学校](https://www.npa.go.jp/keidai/)（東京都府中市）、[科学警察研究所](https://www.npa.go.jp/nrips/jp/index.html)、皇宮警察本部の3機関。警察大学校には令和7年4月にサイバーセキュリティ対策研究センターが新設された。

地方機関は、東北・関東・中部・近畿・中国四国・九州の6管区警察局、四国警察支局、東京都・北海道の警察情報通信部、その他の管区警察局の情報通信部。

## 主要業務（情報系学生関連）

- **サイバー犯罪対策**: [サイバー攻撃対策](https://www.npa.go.jp/bureau/cyber/what-we-do/cyberattack.html)。ランサムウェア、Emotet、フィッシング、不正アクセス、DDoS攻撃等の個別事案対策。外国背景集団（BlackTech、ラザルス、APT40、Salt Typhoon等）への対処
- **デジタルフォレンジック**: [デジタル・フォレンジック](https://www.npa.go.jp/bureau/cyber/what-we-do/digitalforensics.html)。押収電子機器からの電磁的記録の抽出・可視化、民間企業・研究機関との技術協力
- **警察情報通信**: 警察通信網、無線、衛星。次期高度警察情報通信基盤システム
- **科学捜査**: [科学警察研究所](https://www.npa.go.jp/nrips/jp/index.html) による法科学鑑定、犯罪行動科学、交通科学
- **国際連携**: [国際的な警察活動](https://www.npa.go.jp/bureau/soumu/kokusai/kokusai.html)。FBI・Europol等の外国捜査機関、ICPOを通じた国際共同捜査、情報交換、職員派遣
- **官民連携**: [官民連携の推進](https://www.npa.go.jp/bureau/cyber/what-we-do/ppp.html)。サイバー防犯ボランティア、テクニカルアドバイザー、[日本サイバー犯罪対策センター（JC3）](https://www.jc3.or.jp/) との連携

## 採用情報

採用主体は警察庁。[採用情報](https://www.npa.go.jp/about/recruitment/index.html)に掲載される主な採用区分は次のとおり。情報系学生に特筆されるのは「警察庁デジタル採用」「警察庁サイバー採用」の2枠。

| 区分 | 応募ルート | 主な配先・業務 |
| --- | --- | --- |
| [警察庁デジタル採用](https://www.npa.go.jp/about/recruitment/kubun_ippansyokudigital.html) | [国家公務員一般職試験](https://www.jinji.go.jp/saiyo.html)（大卒程度・全試験区分から応募可） | 長官官房技術企画課。情報システム整備の企画立案、開発（内製・委託）、維持管理、インシデント対応 |
| [警察庁サイバー採用](https://www.npa.go.jp/about/recruitment/kubun_senkocyberhontyo.html) | **情報処理技術者試験等合格者選考**（人事院試験不要）。応用情報技術者、ITストラテジスト、ネットワークスペシャリスト、情報処理安全確保支援士等 | 本庁または関東管区警察局サイバー特別捜査部。サイバー犯罪に悪用された電子機器等の解析、サイバー攻撃の予兆把握、不正プログラム解析 |
| [情報処理技術者選考採用（地方機関）](https://www.npa.go.jp/about/recruitment/kubun_senkocybertiho.html) | 同上 | 各地方機関で情報処理技術分野を中心に勤務 |
| 総合職事務系（警察庁警察官） | 総合職試験 | 警察行政全般 |
| 総合職技術系（警察庁技官） | 総合職試験 | 情報通信、通信技術、科学捜査 |
| 一般職事務系（警察庁スペシャリスト警察官） | 一般職試験（大卒程度） | 警察行政スペシャリスト |

[警察庁デジタル採用](https://www.npa.go.jp/about/recruitment/kubun_ippansyokudigital.html) と [警察庁サイバー採用](https://www.npa.go.jp/about/recruitment/kubun_senkocyberhontyo.html) の本庁勤務の初任給は**28.7万円以上**（地域手当・本府省業務調整手当含む、職歴加算あり）。地方機関採用は23.2万円以上。賞与は年2回（約4.65月分）。警察庁サイバー採用は完全週休二日制。

### 令和7年4月1日現在の総合職採用実績

[区分試験別・府省等別採用状況（令和7年4月1日現在）](https://www.jinji.go.jp/content/000012088.pdf)における警察庁の総合職採用実績は計31人（うち女性11人）。うち大卒程度試験デジタル区分22人（同8人）、院卒者試験デジタル区分からの採用実績はなし。

警察庁は大卒程度デジタル区分の採用数が府省庁全体（94人）の2割超を占め、情報系学生の主要な官庁入り口の一つ。加えて人事院試験を経ない「情報処理技術者選考採用」があり、[2026年採用実績](https://www.npa.go.jp/about/recruitment/kubun_senkocyberhontyo.html)は本庁2人、地方機関14人。

:::warn
採用実績は年度ごとに増減する。2027年度の採用予定は[府省等別採用予定数及び官庁訪問窓口一覧](https://www.jinji.go.jp/content/000015294.pdf)で確認する。
:::

## 予算

[令和8年度 警察庁予算の概要](https://www.npa.go.jp/policies/budget/r8/r8tousyoyosan.pdf)による。令和8年度予算総額は3,117億1,900万円（前年度比 +290万円）。うち警察庁分は2,879億2,900万円。

施策別予算の主なものは次のとおり。

| 施策 | 令和8年度 | 令和7年度 |
| --- | ---: | ---: |
| サイバー空間の脅威への対処 | **6,679百万円** | 5,692百万円 |
| テロ対策と大規模災害等への対処 | 10,206百万円 | 10,041百万円 |
| 安全かつ快適な交通の確保 | 18,952百万円 | 19,156百万円 |
| 科学技術を活用するなどした緻密かつ適正な捜査の推進 | 9,706百万円 | 9,395百万円 |
| 組織犯罪対策の推進 | 4,026百万円 | 3,659百万円 |
| 生活の安全を脅かす犯罪対策の推進 | 4,006百万円 | 3,743百万円 |
| 警察基盤の充実強化 | 22,796百万円 | 25,957百万円 |

「サイバー空間の脅威への対処」66億7,900万円の内訳は、対処能力の向上53億8,000万円、人的基盤の強化・研究7億1,100万円、官民・国際連携5億8,800万円。

[令和8年度概算要求](https://www.npa.go.jp/policies/budget/r8/gaisanyokyu/r8tousyoyosan.pdf)における国家公務員増員要求は146人、地方警察官増員要求は475人（福島県警察期限付増員92人を除く）。増員の主目的はサイバー空間の脅威への対処能力強化、匿名・流動型犯罪グループ対策、警察業務のデジタル化・高度化。新設要求として、サイバー企画課に「サイバー人材育成指導室（仮称）」を掲げる。
