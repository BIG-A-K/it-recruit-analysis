防衛装備庁（ATLA）は、防衛装備品の研究開発、調達、装備移転を一元的に担う[防衛省](/companies/mod/)の外局。英称は Acquisition, Technology & Logistics Agency。本庁の所在地は〒162-8870 東京都新宿区市谷本村町5-1。

装備品のライフサイクル（研究、開発、生産、維持・整備、補給、用途廃止）を通じたプロジェクト管理と、[防衛生産・技術基盤の強化](https://www.mod.go.jp/atla/soubichou_gaiyou.html)を所掌する。情報系学生の主な配先は、情報・通信、AI、サイバー、電磁波、宇宙の技術を担当する新世代装備研究所と、革新型・実証型のブレークスルー研究を担う防衛イノベーション科学技術研究所。

## 組織

[内部部局](https://www.mod.go.jp/atla/soshiki/kanbulist_r080807.pdf)は長官官房と5部。長官官房には装備官、装備開発官、艦船設計官などを置く。

| 内部部局 | 主要業務 |
| --- | --- |
| 長官官房 | 総務、人事、会計、監察監査・評価、装備開発 |
| 装備政策部 | 装備政策、国際装備、装備保全管理 |
| プロジェクト管理部 | 装備品のライフサイクルを通じたプロジェクト管理、事業計画・監理、次期戦闘機 |
| 技術戦略部 | 技術戦略、技術計画、技術振興、革新技術戦略 |
| 調達管理部 | 調達企画、原価管理 |
| 調達事業部 | 需品・武器・電子音響・艦船・航空機・輸入の調達 |

[新世代装備研究所](https://www.mod.go.jp/atla/shinsouken.html)は防衛エレクトロニクス部門と宇宙領域の技術を担当し、統合幕僚監部、陸・海・空自衛隊、情報本部が使用する装備品の研究を行う。研究部はAI・サイバーネットワーク研究部、宇宙・センサ研究部、電子対処研究部の3部。AI・サイバーネットワーク研究部はAI応用技術、情報処理技術、通信ネットワーク技術、サイバー技術とそのシステム化技術を扱う。

[防衛イノベーション科学技術研究所](https://www.mod.go.jp/atla/disti.html)は2024年10月に創設。省外からプログラムマネージャを採用し、革新型ブレークスルー研究と、民生の先端技術を取り入れる実証型ブレークスルー研究を実施する。

## 主要業務（情報系学生関連）

- **サイバー防護技術**: 装備システムを標的としたサイバー攻撃に対し、被害拡大防止と装備システムの運用継続を両立する技術の研究
- **AI・通信ネットワーク**: AI応用技術、情報処理技術、通信ネットワーク技術とそのシステム化技術の調査研究
- **センサ・電子戦**: 次世代赤外線センサ技術、高出力レーザ技術、レーダ反射特性評価（RCS計測とシミュレーションによるステルス性評価）
- **プロジェクト管理**: 装備品のライフサイクルを通じた事業監理、コスト・納期・品質の管理
- **次期戦闘機**: [英国・イタリアとの共同開発](https://www.mod.go.jp/j/policy/defense/nextfighter/index.html)、および連携する無人機の研究開発
- **国際共同研究**: 無人航空機へ適用するAIに関する日米共同研究、水中自律型無人機に関する日豪共同研究、高出力マイクロ波システムに関する日米共同研究
- **防衛産業のサイバーセキュリティ**: [防衛産業サイバーセキュリティ基準](https://www.mod.go.jp/atla/cybersecurity.html)の整備

## 採用情報

採用主体は防衛装備庁。新卒は[研究職](https://www.mod.go.jp/atla/saiyou/index.html)と[行政職](https://www.mod.go.jp/atla/saiyou_gyosei/index.html)の2区分で、いずれも人事院の試験に合格したうえで官庁訪問を経る。

| 区分 | 応募ルート | 主な業務 |
| --- | --- | --- |
| [研究職（総合職）](https://www.mod.go.jp/atla/saiyou/saiyo_joho/boshuyoko_sogo.html) | 国家公務員採用総合職試験（院卒者試験・大卒程度試験）の「デジタル」「工学」「数理科学・物理・地球科学」「化学・生物・薬学」「農業科学・水産」「農業農村工学」「教養」区分 | 防衛装備品の研究開発、プロジェクトリーダー、装備行政、国際共同研究開発 |
| [研究職（一般職）](https://www.mod.go.jp/atla/saiyou/saiyo_joho/boshuyoko_sogo.html) | 国家公務員採用一般職試験（大卒程度試験）の「デジタル・電気・電子」「機械」「物理」「化学」「農業農村工学」「教養」区分、および高卒者試験の「技術」区分 | 同上 |
| [行政職](https://www.mod.go.jp/atla/saiyou_gyosei/index.html) | 国家公務員採用一般職試験（大卒程度試験・高卒者試験） | 装備行政、調達、人事、会計 |
| [研究職 選考採用（主任研究官級）](https://www.mod.go.jp/atla/saiyou_chuto/kenkyu.html) | 選考（民間企業等での職務経験者） | 総合職技術系研究職相当の研究開発 |
| [行政職 中途採用（選考採用）](https://www.mod.go.jp/atla/saiyou_gyosei/chuto_ippan.html) | 選考（係長級） | 一般職行政職相当の業務 |
| [行政職 任期付隊員](https://www.mod.go.jp/atla/saiyou_gyosei/ninki.html) | 選考 | 技術調査など、募集ごとに指定された業務 |

研究職技官の勤務地は本庁（東京都新宿区）と各研究所・試験場。研究所は立川市、相模原市、目黒区、世田谷区、渋谷区に、試験場は千歳市、下北郡、各務原市にあり、支所は土浦（茨城県阿見町）、新島（東京都新島村）、川崎市、飯岡（千葉県旭市）、岩国市に置かれる。
