## 採用情報

### 新卒

採用主体は募集要項に記載された法人ごとに異なる。[募集要項](https://nttdata-recruit.com/recruit/requirements.html)は2027年度新卒採用が対象で、応募資格は「2026年4月から2027年3月末までに国内外の高等専門学校または、4年制以上の大学学部・修士・博士課程を卒業・修了（見込み）の方」。

#### 初任給

2026年4月初任給予定額は次のとおり。

| グレード※1 | 学歴区分 | 初任給予定額 |
| --- | --- | --- |
| グレード5 | — | 322,540円 |
| グレード6 | 修士了 | 312,000円 |
| グレード6 | 学士卒 | 300,000円 |
| グレード6 | 高専卒 | 282,000円 |

<p class="section-note"><small>※1 グレードは社員の職務や役割に応じた等級で、初任給や昇給の基準となる。募集要項はグレード5に学歴区分を付していない。</small></p>

昇給は6月、賞与は年2回（6月、12月）。諸手当は子育て・介護手当、リモートワーク手当ほか。

#### 勤務時間

標準的な始終業時刻は8:30〜17:00（うち休憩時間60分）。フレックスタイム制のフレキシブルタイムは5:00〜10:00および15:00〜22:00、コアタイムは10:00〜12:00および13:00〜15:00。裁量労働制（みなし勤務時間7時間30分）の導入もある。

#### 職種

| 職種 | 業務内容 |
| --- | --- |
| 営業 | 顧客ニーズの把握、プランの創造・提案 |
| SE | サービスの開発・運用・維持保守 |
| [R&D](https://nttdata-recruit.com/job/job_r-and-d.html) | 研究開発 |
| [コンサル](https://nttdata-recruit.com/job/job_consultant.html) | 意思決定支援 |
| スタッフ | 法務・財務・人事 |
| 建築系・電力系ファシリティマネジメント | データセンター管理 |

**R&D**の対象は、AI、機械学習、デジタルツイン、量子コンピュータなどの先進技術系と、SIの実施効率を高めるツール整備やシステムアーキテクチャパターン整備などの基盤系技術の2系統。活動は、論文執筆・コミュニティ活動・学会などの技術動向調査からなる研究と、新技術の実装・サービス開発検証・モック作成・技術支援からなる開発に分かれる。

**SE**は、顧客の要求の把握、仕様の決定、設計、開発・テストを担い、あわせて予算・人員・進捗のマネジメント業務を持つ。職種はプロジェクトマネージャ、業務SE、方式SEの3区分。プロジェクトマネージャは受注（予算編成、プロジェクト範囲の選定）、実現方式・メンバ・スケジュールの管理、進捗・品質・コストの管理、顧客対応を担当する。業務SEは設計・開発・導入、要件定義から運用保守、トラブル対応を担当する。方式SEはサーバと端末、サーバ同士をつなぐネットワークの構築・運用・保守を担当する。

**建築系・電力系ファシリティマネジメント**の対象設備は、建築系がデータセンターの電気設備、空調設備、防災設備、情報通信設備、電力系が受電設備、非常用発電設備、無停電電源装置（UPS）。

#### 研修・休暇

研修は、新入社員研修、トレーナー制度、ビジネススキルトレーニング、プロフェッショナルスキルトレーニング、自己啓発支援、海外留学制度。

休暇は、週休2日制、祝日、年末年始休日、夏季休暇、年次有給休暇20日、特別休暇（慶弔ほか）、病気休暇、ライフプラン休暇、産前・産後休暇、介護休暇、看護休暇、不妊治療サポート休暇。

<p class="section-note"><small>特別休暇（出産・育児・生理）および病気休暇は試用期間中は無給。介護休暇、看護休暇、不妊治療サポート休暇は無給。</small></p>

## 事業内容

報告セグメントは国内事業と海外事業の2区分。

| 報告セグメント | 事業内容 |
| --- | --- |
| 国内事業 | 国内顧客向けのコンサルティング、システム開発、運用・保守 |
| 海外事業 | 海外拠点による現地顧客向けサービス、日本企業の海外展開支援、オフショア開発 |

[採用サイトの事業紹介](https://nttdata-recruit.com/business/field.html)は、国内の事業を顧客の業種で次の9分野に分ける。

| 分野 | 内容 |
| --- | --- |
| 官公庁・自治体・教育 | 税務、雇用・労働、貿易、交通などの公共システムの開発・運用。地域社会のシステムや教育現場の支援 |
| 医療・ヘルスケア | 健康管理、地域医療連携、救急搬送などのシステム・サービス |
| 銀行・保険・証券 | 金融機関向けの個別・共同利用型システム、アウトソーシングによる業務効率化 |
| クレジット・決済 | 金融機関・小売・行政間の大規模ネットワーク、電子マネーやカード認証によるキャッシュレス化 |
| 通信・放送 | 通信・放送業界のシステム基盤、ビリング、顧客管理システムの開発・運用 |
| 電力・ガス | スマートコミュニティなど次世代社会インフラのITソリューション |
| 製造・物流 | 生産から販売・物流までの効率化、システム開発とITサービスによるグローバルな業務支援 |
| 流通・サービス | 流通・サービス業向けのソリューション・サービス |
| 基盤技術 | クラウド、OSS、ビッグデータ、セキュリティ、スマートデバイスによるIT基盤の提供 |

海外事業の関わり方は4通りある。国内で確立した仕組みを海外へ展開する。日本企業の海外進出をシステムインテグレーターとして支援する。海外企業の日本市場参入を支援する。ソフトウェア開発を海外グループ会社へ委託するオフショア開発を行う。

| 区分 | 事例 |
| --- | --- |
| 海外の関係者と協力して開発する | [AI画像診断支援ソリューション](https://www.nttdata.com/jp/ja/trends/case/2020/021400/)：放射線科医による画像診断を支援するAIソリューションの構築 |
| 海外の関係者と協力して開発する | [外航貨物保険・保険金支払い実証実験](https://www.nttdata.com/jp/ja/case/2018/112201/)：世界8か国の関係者による、外航貨物保険の保険金請求へのブロックチェーン技術の適用 |
| 日本企業の海外進出を支援する | [グローバルSCMソリューション](https://www.nttdata.com/jp/ja/lineup/global_scm_solution/)：グローバルに事業展開する企業のサプライチェーン課題の解決支援 |
| 日本企業の海外進出を支援する | [SAPグローバル・アウトソーシング](https://www.nttdata.com/jp/ja/lineup/sap_global_outsourcing/)：業務とシステムの標準化による日系企業のガバナンス強化 |

持株会社である株式会社NTTデータグループは、このほかに戦略（イノベーション、マーケティング、戦略投資）、管理、研究開発、ガバナンス確保を担う。これらの機能の一部は関連会社が担当する。
