[TOTO株式会社](https://jp.toto.com/)は1917年に衛生陶器メーカーとして創業した。陶器の焼成技術を基盤に、衛生陶器、ウォシュレット、浴槽、ユニットバスルーム、水栓金具、システムキッチン、洗面化粧台、環境建材、福祉機器などの住宅設備機器を水まわり中心に世界で展開する。このセラミックの技術は新領域のセラミック事業にも展開され、半導体製造装置向けのファインセラミックスを手がける。

社是は「愛業至誠」。TOTOグループ企業理念として「社会の発展に貢献し、世界の人々から信頼される企業を目指します」と掲げ、水まわりを中心とした生活文化の創造、質の高い商品・サービスの提供、資源とエネルギーを大切にする活動、一人ひとりの個性を尊重する職場づくりを示す。

## 事業内容

TOTOの事業は、水まわりの住宅設備機器を世界で展開する「グローバル住設事業」と、半導体向け素材を担う「セラミック事業」の2軸で構成される。

| 報告セグメント | 製品・サービス例 |
| --- | --- |
| 日本住設事業 | 衛生陶器、ウォシュレット、システムトイレ、浴槽、ユニットバスルーム、水栓金具、システムキッチン、洗面化粧台、環境建材、福祉機器、パブリック向け商品 |
| 米州事業 | 水まわりを中心とする住宅設備機器と関連サービス |
| アジア・オセアニア事業 | 水まわりを中心とする住宅設備機器と関連サービス |
| 欧州事業 | 水まわりを中心とする住宅設備機器と関連サービス |
| 中国大陸事業 | 水まわりを中心とする住宅設備機器と関連サービス |
| セラミック事業 | 半導体製造装置向けファインセラミックス（静電チャック、エンジニアリングセラミックスなど） |

:::info
セラミック事業の主力は静電チャックである。半導体製造装置の内部でシリコンウェーハを吸着して固定するセラミック部品で、成膜やエッチングなどのウェーハ処理が行われる間、ウェーハを正確な位置に保持し続ける。衛生陶器メーカーとして始まったTOTOは、陶器の焼成で培ったセラミックの技術を高純度・高精度が求められる半導体分野へ展開し、次世代半導体製造装置や半導体露光装置向けの製品開発を進める。顧客は半導体製造装置メーカーで、世界的なAI需要の拡大に伴う半導体市場の伸長と、既設工場の稼働率向上に伴う交換需要とを背景に、同事業の売上は前年比で拡大している。
:::

住宅設備機器の内容と商品例は[TOTO企業概要](https://jp.toto.com/company/profile/information/)・[TOTO商品一覧](https://jp.toto.com/products/)。セラミック事業の製品・顧客・業績動向と報告セグメントの名称・年度別実績は有価証券報告書に基づく。
