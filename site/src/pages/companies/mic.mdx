[総務省](https://www.soumu.go.jp/english/mic_slogan.html)のスローガンは「くらしの中に総務省」。
行政制度、地方自治、情報通信、統計を担う中央省庁である。

2001年の中央省庁再編で発足し、本省は東京都千代田区霞が関2-1-2にある。

[内部部局](https://www.soumu.go.jp/menu_sosiki/annai/soshiki/index.html)には国際戦略局、情報流通行政局、総合通信基盤局、統計局、サイバーセキュリティ統括官などを置く。

## 採用情報

### 新卒

2027年度新卒採用では、本省と統計局が国家公務員採用試験の合格者を対象に、それぞれ官庁訪問を実施する。
官庁訪問は各府省の採用面接を指す。

| 採用区分 | 応募経路と募集状態 | 主な仕事 | 主な勤務地 |
| --- | --- | --- | --- |
| 総合職（事務系） | 総合職試験後に官庁訪問。官庁訪問は終了 | 行政制度、地方自治、政策の企画立案 | 本省（東京） |
| 一般職（事務系） | 一般職試験後に官庁訪問。官庁訪問は終了 | 制度運用、調査、政策実施 | 本省（東京） |
| [総合職（技術系、情報通信行政）](https://www.soumu.go.jp/menu_syokai/saiyou/isougou.html) | 総合職試験後に官庁訪問。官庁訪問は終了 | 情報通信技術（ICT）政策、電波と通信制度、サイバーセキュリティ政策 | 本省（東京） |
| [一般職技術系（情報通信行政）](https://www.soumu.go.jp/menu_syokai/saiyou/i2syu.html) | 一般職試験後に官庁訪問。2026年7月27日から採用者決定まで官庁訪問を継続 | 電波監視、通信制度の運用、技術調査 | 本省（東京） |
| [統計局（総合職、一般職）](https://www.stat.go.jp/info/saiyou/index.html) | 各試験後に統計局の官庁訪問。官庁訪問は終了 | 公的統計の企画、調査、政府統計ポータルサイト「e-Stat」の運用 | 統計局（東京都新宿区） |

地方総合通信局と消防庁は本省とは別に採用し、上表には含めない。
地方総合通信局の採用者は採用地域で電波監視や通信行政を担う。

[2026年度の本省初任給](https://www.jinji.go.jp/saiyo/syokai.html)は、東京都特別区の地域手当と本府省業務調整手当を含む月額例で次のとおりである。

| 試験区分 | 初任給の月額例 |
| --- | ---: |
| 総合職（院卒） | 317,520円 |
| 総合職（大卒） | 301,200円 |
| 一般職（大卒） | 287,600円 |

時間外勤務手当は別途支給される。
賞与に当たる期末・勤勉手当は年間4.65か月分である。
標準的な年間給与は開示されていない。
1日の勤務時間は7時間45分である。

## 事業内容

[本文で扱う行政組織](https://www.soumu.go.jp/menu_sosiki/annai/soshiki/index.html)と政策分野は次のとおりである。

| 組織 | 主な行政分野 |
| --- | --- |
| 国際戦略局 | 情報通信政策の国際調整、研究開発、国際標準化 |
| 情報流通行政局 | 放送、情報流通、情報通信サービスの利用環境整備 |
| 総合通信基盤局 | 電気通信事業、電波利用、通信基盤の安全確保 |
| 統計局 | 国勢調査などの公的統計、e-Statの運用 |
| サイバーセキュリティ統括官 | 情報通信分野のサイバーセキュリティ政策 |
