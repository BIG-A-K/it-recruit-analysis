総務省（MIC）は、行政基本システムの整備、情報通信行政、地方自治、財政、消防、郵政行政を所管する中央省庁。英称は Ministry of Internal Affairs and Communications。所在地は〒100-8926 東京都千代田区永田町2-1-2 第二庁舎。法人番号は2000012020001。

## 組織

総務省の[情報通信部門](https://www.soumu.go.jp/menu_syokai/saiyou/isougou.html)が情報系学生の主要な配先。内部部局のうち情報通信行政を担うのは次の4局とサイバーセキュリティ担当。

| 内部部局 | 主要業務 |
| --- | --- |
| [情報流通行政局](https://www.soumu.go.jp/main_sosiki/joho_ryutsu/index.html) | 内容産業、著作権、放送、流通行政 |
| [情報通信国際戦略局](https://www.soumu.go.jp/main_sosiki/joho_kokusai/index.html) | ICT戦略、国際標準化、Beyond 5G |
| [総合通信基盤局](https://www.soumu.go.jp/main_sosiki/sogo_kiban/index.html) | 電波政策、周波数管理、電気通信事業法、IP化移行、ICT安全安心 |
| [統計局](https://www.stat.go.jp/) | 国勢調査、統計制度、e-Stat |
| [サイバーセキュリティ担当](https://www.soumu.go.jp/main_sosiki/cybersecurity/index.html) | ICT領域のサイバーセキュリティ政策 |

行政・自治に関する内部部局は、大臣官房、行政管理局、行政評価局、自治行政局、自治財政局、自治税務局。

[地方支分部局](https://www.soumu.go.jp/menu_syokai/saiyou/kanku_recruit/index.html)は管区行政評価局（7ブロック）と[総合通信局](https://www.soumu.go.jp/menu_syokai/saiyou/02kanbo01_03000208.html)（北海道・東北・関東・信越・北陸・東海・近畿・中国・四国・九州・沖縄）。総合通信局は電波監視、周波数管理、通信技術系の業務を担う。特別の機関として[消防庁](https://www.fdma.go.jp/)を置く。

## 主要業務（情報系学生関連）

- **電波・周波数政策**: 動的周波数利用、ITS、災害時無線通信
- **電気通信事業規制**: MVNO支援、SIM解除義務化、資費源泉規制、IP化移行
- **ICT安全・安心**: ICTサービス安全安心懇談会、消費者保護
- **国際標準化・Beyond 5G**: [情報通信国際戦略局](https://www.soumu.go.jp/main_sosiki/joho_kokusai/index.html) が所管。6G戦略
- **統計**: 国勢調査、[e-Stat](https://www.e-stat.go.jp/) の運営、データ連携
- **地域ICT・スマートシティ**: 地方自治体のICT化、住民基本台帳、デジタル自治
- **サイバーセキュリティ**: ICT領域の官民連携、インシデント対応

:::info
ガバメントクラウド・行政共通基盤、マイナンバー制度は2021年（令和3年）9月のデジタル庁発足時に移管された。個人情報保護行政は個人情報保護委員会（内閣府）の所管。
:::

## 採用情報

| 区分 | 特徴 |
| --- | --- |
| [行政・技術系（総合職）情報通信部門](https://www.soumu.go.jp/menu_syokai/saiyou/isougou.html) | 総合職試験の行政・技術系区分を経て採用。Beyond 5G、IoT、放送、ネットワーク、サイバーセキュリティ等の情報通信行政全般を担う |
| [専門職（行政系）](https://www.soumu.go.jp/menu_syokai/saiyou/j3syu.html) | 統計署、行政評価・管理などを担う |
| [専門職 技術系（情報通信部門）](https://www.soumu.go.jp/menu_syokai/saiyou/i2syu.html) | 総合通信局等で電波・通信技術を担う |
| [消防庁 行政・技術系](https://www.fdma.go.jp/about/saiyo/saiyo002.html) | 消防庁の行政・技術系採用 |
| [地方行政評価支部門](https://www.soumu.go.jp/menu_syokai/saiyou/kanku_recruit/index.html) | 管区行政評価局等の地方支分部局 |
| [総合通信局・総合通信司令部](https://www.soumu.go.jp/menu_syokai/saiyou/02kanbo01_03000208.html) | 専門職 行政系・技術系。電波監視、通信技術 |
| [経験者選任採用](https://www.soumu.go.jp/menu_syokai/saiyou/keikensya_senkou_jimu.html) | 行政系・技術系・調査系・業務系・専門系 |
| [一般選任採用](https://www.soumu.go.jp/menu_syokai/saiyou/ippan_senkou.html) | 行政系・技術系・調査系・業務系・通信系 |

### 令和7年4月1日現在の総合職採用実績

[区分試験別・府省等別採用状況（令和7年4月1日現在）](https://www.jinji.go.jp/content/000012088.pdf)における総務省の総合職採用実績は計59人（うち女性21人）。うち院卒者試験デジタル区分5人。大卒程度試験のデジタル区分からの採用実績はなし。

[情報通信部門の採用実績](https://www.soumu.go.jp/menu_syokai/saiyou/isougou.html)（行政・技術系 大卒程度）の年度別推移は令和2年度6人、令和3年度5人、令和4年度10人、令和5年度9人、令和6年度7人、令和7年度8人、令和8年度8人（カッコ内は女性）。

:::warn
採用実績は年度ごとに増減する。2027年度の採用予定は[府省等別採用予定数及び官庁訪問窓口一覧](https://www.jinji.go.jp/content/000015294.pdf)で確認する。
:::
