**コンピュータの性能を、極限まで引き出す**

> ソフトウェアを効率的に動かすことで、できなかった計算をできる計算にする。コンピューティングに必要な消費電力を低減する。

これはフィックスターズが掲げるパーパスだ。2002年創業のフィックスターズは、ハードウェアを理解したうえでソフトウェアを書き換え、処理速度・応答時間・電力効率・計算コストを改善する「パフォーマンスエンジニアリング」を専門とする。

単なる開発受託ではない。顧客の既存ソフトウェアのボトルネックを観測し、アルゴリズム、並列化、メモリ、コンパイラ、GPU・CPU・FPGAなどの実行基盤まで掘り下げて改善する。その技術を、AI開発環境やGPU性能分析、量子最適化などの自社製品にも展開する。

**事業の見方**

フィックスターズの事業は、技術支援と自社製品の2つを行き来する。

| 役割 | 何を提供するか |
| --- | --- |
| パフォーマンスエンジニアリング | お客様のソフトウェアを観測し、ボトルネックを特定して高速化・省電力化する |
| サービス | 組込みAIモデルの移植・最適化、AI開発環境、FPGA、量子、フラッシュメモリ向けの専門開発 |
| プロダクト | AI/LLMの性能可視化、ローカルAI環境、量子最適化をプロダクトとして提供 |

20年以上にわたる高速化案件で蓄積した知見を、個別案件だけでなく製品や開発環境へ展開する点が特徴だ。[公式サイト](https://www.fixstars.com/ja/products-services/advantages)は、100社を超える顧客、リピート率99%以上、CPU・GPU・FPGAなど多様なプロセッサへの対応を強みとして掲げる。

## 採用情報

### 新卒

採用主体は株式会社フィックスターズ。新卒はソフトウェアエンジニアを募集する。待遇の具体的な金額は募集要項に記載されていない。

勤務地は東京都港区芝浦の本社を基本とし、公式[採用FAQ](https://www.fixstars.com/ja/recruit/faq)は原則転勤なしとする。

| ステップ | 内容 |
| --- | --- |
| 1. エントリー | [公式エントリーフォーム](https://herp.careers/v1/fixstars/requisition-groups/f2a22436-68e3-4dc6-8e49-6a073acd6ef1)から応募 |
| 2. 書類選考 | 応募内容に基づく選考 |
| 3. 面接・適性検査 | 人事・現場・役職者との面接。研究発表・ライブコーディング、オンライン適性検査 |
| 4. 最終面接 | 役員面接 |
| 5. オファー面談 | 条件提示と入社後の確認 |

:::info
選考は状況により変更される。配属先は保有スキル、希望、会社の方針を総合して決定される。選考期間は調整を含めて約1か月半。社外活動、資格取得、社内大学などの成長支援制度がある。
:::

**仕事の特徴**

- ハードウェアの特性を理解してソフトウェアを最適化するため、低レイヤからアルゴリズムまで扱う。
- 新卒社員の配属先は、AI・画像処理・数値計算・組込み・量子など、プロジェクトと適性により決まる。
- 20年以上の顧客案件と自社製品の両方に関われるため、研究成果を実装へ移す力と、実装を性能指標で検証する力が求められる。
