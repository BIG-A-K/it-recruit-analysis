## 事業内容

報告セグメントごとの事業内容は次のとおり。

| 報告セグメント | 事業内容 |
| --- | --- |
| 産業IT | 製造、通信、エネルギー、流通、サービス、メディア等の顧客向けに、基幹系システムや生産管理システムなどのITソリューションを提供。自動車業界向けには、組み込みソフトウェア開発やミドルウェア提供をグローバルに展開 |
| 金融IT | 銀行、生損保、証券などの金融機関向けの金融システムの構築 |
| ITソリューション | ERPパッケージ「ProActive」やSAP、Oracleの導入・保守。BPOサービスの提供 |
| ITプラットフォーム | ITインフラ、CAD、CAE分野のシステム構築 |
| ITマネジメント | データセンター「netXDC」を中心とするアウトソーシング、クラウドインフラの提供 |
| その他 | ソフトウェア開発、システム運用、リモート開発 |

[提供サービス](https://www.scsk.jp/corp/activities/index.html)の区分は報告セグメントとは別で、次の7分類。

| サービスカテゴリ | 概要 |
| --- | --- |
| BPO（Business Process Outsourcing） | 顧客業務の一部を一括受託し、コンタクトセンターやECフルフィルメントなどを提供 |
| ITハード・ソフト販売 | セキュリティ、ネットワーク、サーバー・ストレージ、CAD、CAEなどの製品販売・構築・サポート |
| ITマネジメント | オンプレミスからクラウドまで、ITシステムの保守運用と継続的な改善を行うITサービスマネジメント |
| ITインフラ構築 | インフラ最適化のためのアセスメント、設計・構築、運用設計 |
| コンサルティング | 経営戦略に沿ったIT戦略の策定から、業務領域ごとのIT企画・実現まで |
| システム開発 | SoR（System of Record）からSoE（System of Engagement）までの開発 |
| 検証サービス | 独自の検証理論と最新技術によるテストケースに基づくソフトウェアの評価・検証 |
