特許庁（JPO）は、特許、実用新案、意匠、商標の産業財産権について、出願の審査、登録、審判を担う[経済産業省](/companies/meti/)の外局。英称は Japan Patent Office。所在地は〒100-8915 東京都千代田区霞が関3-4-3。法人番号は2000012090003。

情報系学生の主な配先は、電気および通信に関する発明の審査を担当する審査第四部。特許審査官は担当する技術分野の知識に加え、特許法などの法律知識と、外国文献調査のための語学力を用いて出願された発明を審査する。

## 組織

[経済産業省組織令](https://laws.e-gov.go.jp/law/412CO0000000254)第135条から第142条により、特許庁には7つの部が置かれる。発明の審査は技術分野ごとに審査第一部から審査第四部に分かれる。

| 部 | 所掌事務 |
| --- | --- |
| 総務部 | 人事、特許特別会計の経理、工業所有権に関する情報システムの整備・管理、調査・統計、公報の刊行、分類、弁理士、国際協力 |
| 審査業務部 | 出願書類の方式審査、工業所有権の登録、商標の審査 |
| 審査第一部 | 農林畜水産物の採取・加工、建設、原子力、測定、事務用品、日用品に関する発明の審査、意匠の審査 |
| 審査第二部 | 機械に関する発明の審査 |
| 審査第三部 | 化学に関する発明の審査 |
| **審査第四部** | **電気および通信に関する発明の審査** |
| 審判部 | 工業所有権に関する審判、特許異議および登録異議 |

各部に置く課の数は総務部7、審査業務部3、審査第一部2、審判部1。課長に準ずる職の数は審査第一部8人、審査第二部から審査第四部が各7人、審判部129人。

[審判部](https://www.jpo.go.jp/introduction/soshiki/yakuwari.html)は、審査結果に対する不服について、地方裁判所に代わる第一審としての機能を持ち、民事訴訟法に準じた手続で審理する。

## 主要業務（情報系学生関連）

- **特許審査**: 出願された発明の審査と、実用新案技術評価書の作成。特許協力条約（PCT）に基づく国際調査および国際予備審査を含む
- **電気・通信分野の審査**: 審査第四部が電気および通信に関する発明を担当。ソフトウェア、通信、半導体、電子デバイスに関する出願が対象
- **意匠・商標の審査**: 意匠は審査第一部、商標は審査業務部が担当
- **審判**: 拒絶査定不服審判、無効審判、特許異議および登録異議の審理
- **工業所有権の情報システム**: 総務部が所管。出願・審査・登録の各手続を支える情報システムの整備と管理
- **調査・統計・分類**: 工業所有権に関する調査、統計、特許分類の付与と管理、公報その他の資料の収集・編集・刊行
- **国際協力**: 日米欧の先進国間協力、中国・韓国を含めた五庁協力、途上国への審査協力と人材育成、[特許審査ハイウェイ（PPH）](https://www.jpo.go.jp/introduction/soshiki/yakuwari.html)の推進
- **産業財産権情報の提供**: インターネット公報の発行をはじめとする産業財産権情報提供の拡充

## 採用情報

採用主体は特許庁。[特許審査官](https://www.jpo.go.jp/news/saiyo/kokka/tokkyo/saiyo-info/index.html)は人事院の国家公務員採用総合職試験（大卒程度試験・院卒者試験）の技術系区分に合格した者から、特許庁の面接試験を経て採用される。

| 区分 | 応募ルート | 主な業務 |
| --- | --- | --- |
| [特許審査官](https://www.jpo.go.jp/news/saiyo/kokka/tokkyo/saiyo-info/index.html) | 国家公務員採用総合職試験（院卒者試験・大卒程度試験）の「デジタル」「工学」「数理科学・物理・地球科学」「化学・生物・薬学」「農業科学・水産」「農業農村工学」「森林・自然環境」区分 | 出願された発明の審査、実用新案技術評価書の作成、PCTに基づく国際調査・国際予備審査 |
| [意匠審査官](https://www.jpo.go.jp/news/saiyo/kokka/isho/saiyo-info/index.html) | [総合職・一般職](https://www.jpo.go.jp/news/saiyo/kokka/index.html)の採用区分 | 審査第一部での意匠の審査 |
| [商標審査官](https://www.jpo.go.jp/news/saiyo/kokka/shohyo/saiyo-info/index.html) | [総合職・一般職](https://www.jpo.go.jp/news/saiyo/kokka/index.html)の採用区分 | 審査業務部での商標の審査 |
| [事務職員](https://www.jpo.go.jp/news/saiyo/kokka/jimu/saiyo-info/index.html) | 国家公務員採用一般職試験（大卒程度試験）の行政区分または教養区分 | 制度の企画・立案、海外政府との交渉・協力、中小・ベンチャー企業等への支援 |
| [任期付職員](https://www.jpo.go.jp/news/saiyo/other/ninkitsuki-tokkyo/index.html) | 選考 | 特許審査官、商標審査官補・商標審査官、法制専門官等 |
| [選考採用（常勤職員）](https://www.jpo.go.jp/news/saiyo/other/shogai-dokuji/index.html) | 選考 | 常勤職員の業務 |

[特許審査官の採用](https://www.jpo.go.jp/news/saiyo/kokka/tokkyo/saiyo-info/index.html)は、デジタル、工学、数理科学・物理・地球科学、化学・生物・薬学、農学系といった技術系のあらゆる試験区分から満遍なく行われる。問い合わせ窓口は特許庁審査第一部調整課採用担当。

[事務職員](https://www.jpo.go.jp/news/saiyo/kokka/jimu/saiyo-info/index.html)の配属先は、人事・法令・予算関係・総合調整を担当する総務部門、産業財産権情報の利用促進を図る情報部門、国際機関等との協力を担当する国際部門、産業財産権に関する事務を担当する方式審査部門など。1つのポストを約1年から2年で異動し、一般職事務職員は勤務成績に応じて約7年で係長相当職に昇任する。年度別採用者数は2022年度12人、2023年度22人、2024年度28人、2025年度29人、2026年度28人。

## 予算・定員

特許庁の経理は特許特別会計で行う。[令和8年度当初予算の概要](https://www.meti.go.jp/main/yosan/yosan_fy2026/pdf/01.pdf)における特許特別会計は**1,606億円**（令和7年度当初 1,544億円）。

[令和8年度 主な機構・定員について](https://www.meti.go.jp/main/yosan/yosan_fy2026/pdf/05.pdf)では、経済産業省の新規増81人のうち知的財産政策の推進に22人を充て、AIをはじめとする技術の高度化・複雑化に対応するための審査官を新規に増やす。
