防衛省（MOD）は、わが国の平和と独立を守り、国の安全を保つことを任務とする中央省庁。英称は Ministry of Defense。所在地は〒162-8801 東京都新宿区市谷本村町5-1。法人番号は9000012120001。

陸・海・空の領域に加え、宇宙・サイバー・電磁波の領域における作戦能力を有機的に結合させ、陸・海・空自衛隊の部隊を連携させた統合作戦を行う。情報系学生の主な配先は、電波情報の解析を担う情報本部、数理的分析評価を担う各自衛隊の能力分析部門、サイバーセキュリティ業務を担う統合幕僚監部。

## 組織

事務官・技官等の[採用予定機関](https://www.mod.go.jp/j/saiyou/ippan_senmon/shokai/index.html)は次のとおり。市ヶ谷の本省には内部部局と本省所在6機関が置かれる。

| 機関 | 主要業務 |
| --- | --- |
| 本省内部部局 | 防衛戦略の策定、防衛力整備、法令および予算の策定、日米同盟強化のための調整・交渉 |
| [統合幕僚監部](https://www.mod.go.jp/j/saiyou/ippan_senmon/shokai/toubaku.html) | 陸・海・空自衛隊の統合運用、サイバーセキュリティ業務 |
| [陸上幕僚監部](https://www.mod.go.jp/j/saiyou/ippan_senmon/shokai/gsdf.html)・[海上幕僚監部](https://www.mod.go.jp/j/saiyou/ippan_senmon/shokai/msdf.html)・[航空幕僚監部](https://www.mod.go.jp/j/saiyou/ippan_senmon/shokai/asdf.html) | 各自衛隊の総務・人事・会計・法務等の行政業務、維持・整備・補給・能力分析等の技術業務 |
| [情報本部](https://www.mod.go.jp/j/saiyou/ippan_senmon/shokai/dih.html) | 電波情報、画像・地理情報、公刊情報の収集・解析、国際軍事情勢の動向分析 |
| [防衛装備庁](/companies/atla/) | 装備品の研究開発、調達、装備移転 |
| [地方防衛局](https://www.mod.go.jp/j/saiyou/ippan_senmon/shokai/rdb.html) | 駐屯地・基地の調査・設計・建設、地方公共団体および地域住民との調整 |
| [防衛大学校](https://www.mod.go.jp/j/saiyou/ippan_senmon/shokai/nda.html)・[防衛医科大学校](https://www.mod.go.jp/j/saiyou/ippan_senmon/shokai/ndmc.html) | 幹部自衛官および医官等の養成、教務事務、学校運営 |

[情報本部](https://www.mod.go.jp/j/saiyou/sougou_research/introduce_dih.html)はわが国唯一の電波情報部門である電波部を持ち、収集した情報の成果を防衛省の各機関、内閣総理大臣、防衛大臣、国家安全保障会議へ提供する。

## 主要業務（情報系学生関連）

- **サイバー防衛体制の強化**: [サイバーセキュリティ](https://www.mod.go.jp/j/approach/defense/cyber/index.html)。サイバー関連部隊の体制強化、サイバー要員化の推進、防衛省・自衛隊のサイバー業務を支える省外人材の確保
- **情報システムの防護**: 防衛省クラウド基盤の整備を含むサイバー防護機能の整備、サイバー領域における意思決定支援システムの整備
- **リスク管理枠組み（RMF）**: 装備品と情報システムに対するリスク管理枠組みの実施
- **電波情報の解析**: 情報本部電波部で、統計・代数学と通信工学の知識を用いてデジタル信号とアナログ信号を解析し、解析用ソフトウェアを開発する
- **能力分析**: オペレーションズ・リサーチを中心とする数理的分析評価により、政策の企画・立案、部隊の運用、装備品の研究開発と維持運用に参画する
- **人材育成・官民連携**: [防衛省サイバーコンテスト](https://www.mod.go.jp/j/approach/defense/cyber/c_contest/index.html)、[IT・セキュリティ人材の確保・育成計画](https://www.mod.go.jp/j/approach/defense/cyber/pdf/human_resource_development_plan.pdf)、サイバーディフェンス連携協議会（CDC）、[日米サイバー防衛政策ワーキンググループ](https://www.mod.go.jp/j/approach/defense/cyber/cdpwg/index.html)

## 採用情報

総合職（研究職）能力分析系の採用時の勤務先は陸上・海上・航空いずれかの自衛隊（幕僚監部または部隊等）で、その後は採用された自衛隊を中心に、内部部局や統合幕僚監部（いずれも市ヶ谷）で勤務することもある。情報系の勤務先は情報本部。

### 令和7年4月1日現在の総合職採用実績

[区分試験別・府省等別採用状況（令和7年4月1日現在）](https://www.jinji.go.jp/content/000012088.pdf)における防衛省の総合職採用実績は計31人（うち女性9人）。うち工学区分は院卒者試験7人、大卒程度試験4人。デジタル区分からの採用実績はなし。

:::info
デジタル区分を対象とする総合職（研究職）情報系は情報本部の採用で、採用者数は年度によって変動します。工学区分を含む技術系の採用は、防衛省本体と[防衛装備庁](/companies/atla/)で別に集計されています。
:::

:::warn
採用実績は年度ごとに増減する。2027年度の採用予定は[府省等別採用予定数及び官庁訪問窓口一覧](https://www.jinji.go.jp/content/000015294.pdf)で確認する。
:::

## 予算

[令和8年度予算の概要](https://www.mod.go.jp/j/budget/yosan_gaiyo/fy2026/yosan_20260408.pdf)による令和8年度の防衛関係費は、歳出ベースで整備計画対象経費8兆8,093億円。契約ベースは8兆2,607億円。

情報系に関わる分野の内訳は次のとおり。

| 分野 | 令和8年度 |
| --- | ---: |
| サイバー領域における能力強化 | **約2,331億円** |
| 研究開発 | 約7,095億円 |

サイバー領域における能力強化の内訳には、サイバー防護機能の整備203億円、サイバー領域における意思決定支援システムの整備39億円、省外のサイバー人材による支援の確保0.4億円が含まれる。施策の柱はサイバー防衛体制の抜本的強化、リスク管理枠組み（RMF）の実施、情報システムの防護、教育・研究機能の強化、防衛産業におけるサイバーセキュリティの強化。
