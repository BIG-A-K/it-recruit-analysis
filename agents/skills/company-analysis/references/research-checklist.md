# 企業分析調査チェックリスト

focus に応じて `就活`、`投資`、または両方の項目を使う。値が非開示の場合は数値を空欄にし、CSVスキーマで定めた `availability` に理由を記録する。

## 調査台帳

各情報について次を記録する。

| 項目 | 内容 |
| --- | --- |
| 値・事実 | 原文の意味を変えない要約または数値 |
| 対象 | 法人名、連結・単体、対象者 |
| 時点 | 基準日、会計年度、募集年度 |
| 単位 | 円、百万円、%、人、時間など |
| 出典 | 資料名、ページまたは節、URL、公表日 |

## 情報源

1. 有価証券報告書・法定開示
2. 決算短信、決算説明資料、統合報告書
3. 公式採用サイト、募集要項、人的資本データ
4. 公式コーポレートサイト、事業紹介
5. 官公庁・取引所などの公的データ

一次情報が取得できない場合のみ二次情報を補助に使い、`sources.csv` の `source_type` を `secondary` とする。

## 企業境界

- 正式社名、ブランド名、証券コード
- 親会社、持株会社、主要子会社
- 採用する法人と雇用条件の適用範囲
- 財務数値の開示法人と連結範囲
- 合併、分社化、会計基準変更による比較不能期間

## 就活

- ミッション、価値観、企業文化として公式に掲げる内容
- 新卒・中途の募集年度、応募期限、選考区分
- 職種、仕事内容、応募資格、配属方法
- 初任給・年収例、固定残業時間と金額、賞与、諸手当
- 勤務地、転勤、リモート勤務、標準労働時間
- 平均年間給与、平均年齢、平均勤続年数、従業員数
- 月残業時間、有給取得、育休取得率などの人的資本指標
- 単体従業員の値が応募先の実態を表すかという適用限界

## 投資

- 事業セグメント、主要製品・サービス、顧客、収益モデル
- セグメント別売上・利益と構成比、地域構成
- 売上高、営業・経常利益、純利益の3期以上の推移
- ROE、自己資本比率、純資産、総資産
- 営業・投資・財務キャッシュフローと現金増減
- 流動資産、流動負債、当座資産の内訳
- 成長要因、競争優位、顧客・製品・地域への集中
- 減損、訴訟、規制、為替、景気循環、資金調達などの主要リスク
- 大型買収・売却・組織再編など比較を歪める一時要因

## 検算

- 表の列が会計年度末か暦年かを明記したか
- 通貨、千・百万・十億の単位を統一したか
- `△`、括弧、マイナス記号を同じ意味で扱ったか
- 売上と利益で連結・単体を混在させていないか
- 流動比率を `流動資産 / 流動負債 * 100` で再計算したか
- 当座資産に棚卸資産や長期資産を含めていないか
- 当座資産の定義が資料にない場合、その算定内訳を明示したか
- キャッシュフロー3区分の合計と現金増減の差に、為替換算等があるか確認したか
- 企業再編や会計基準変更をまたぐ推移に注記したか
- `metrics.csv` と `segments.csv` の出典IDが `sources.csv` に存在するか
- `recruitment.csv` と `company_relations.csv` の出典IDが `sources.csv` に存在するか
- データや注記に評価語や所感が混入していないか（「健全」「高い水準」「特徴的」「注意が必要」「読み取れる」など）
- 数値の変動要因を記録した場合、その説明が開示資料にあり、出典IDが設定されているか
- 企業IDと業界IDの参照先が各マスタに存在するか
- 複合主キーが重複していないか
- `availability=reported` の行に値、単位、出典IDがあるか
